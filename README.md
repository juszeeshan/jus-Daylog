# Jus Daylog front end (GitHub Pages)

Publish this folder. It contains no backend code.

1. Set `API_URL` in `config.js` to your Apps Script `/exec` URL (leave empty for demo mode).
2. Push to GitHub, then Settings > Pages > Deploy from branch (main, root).
3. Planner: `https://<user>.github.io/<repo>/`  Companion: `https://<user>.github.io/<repo>/daylog/`
4. After you push an update, phones keep a cached copy: open the app, close it fully, open it again (twice if needed).

The `/exec` URL in `config.js` is visible to visitors. That is normal; your code and Sheet stay private in Google.
